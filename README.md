# The Orndorff Residence - Ellijay, GA

Static website providing easy access to the exact as-built plans, floor plans, site plan, build measurements, notes, and specifications for The Orndorff Residence at 2781 Old Parker Place Road, Ellijay, GA 30536.

- Home page features the official house rendering
- Dedicated pages for Site Plan and Floor Plans with measurements
- Notes & Specifications extracted directly from the plan set

Built for Farber.Inc. Ready for deployment to Hostinger or any static host.

## Pages
- `/` - Home with rendering and project info
- `/site-plan.html` - Site Plan
- `/floor-plans.html` - Floor Plans & Measurements
- `/notes.html` - Notes, Abbreviations, Finishes, and Specs

Favicon used for branding.
